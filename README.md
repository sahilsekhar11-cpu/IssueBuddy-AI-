# IssueBuddy AI

IssueBuddy AI is an AI-powered application that analyzes GitHub repository issues and generates concise, easy-to-understand summaries using Gemma4. It uses ChromaDB to store issue data, enabling efficient data retrieval and helping developers quickly understand reported bugs, feature requests, and ongoing discussions without reading lengthy issue threads.

Built to simplify issue tracking, IssueBuddy AI helps developers save time, understand problems faster, and focus on solving issues.
